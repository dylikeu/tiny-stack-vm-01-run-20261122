A tiny stack VM for the make.fun bounty: one program answers 40 instances of the tiny stack ISA — 32-bit wrapping integers, a 256-value stack, calls, 256 words of memory, and ten traps with their own exit codes.

## Run

`node main.ts` reads `/input/<id>/program.bin` and `/input/<id>/input.bin` and writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt` for `i001`–`i040`, in one run.
